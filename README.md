# Piyush Shah Portfolio

Static GitHub Pages portfolio for piyushshah.ca.

## How to deploy
Upload all files and folders in this directory to your `piyushshah.github.io` repository. Keep the `CNAME` file for the custom domain.

## Main files
- `index.html`: Website content
- `assets/css/style.css`: Styling
- `assets/js/main.js`: Mobile menu, typing animation, scroll effects
- `resume/Piyush_Shah_Resume.pdf`: Downloadable resume
